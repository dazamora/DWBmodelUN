# gru_maps

Spatial distribution of DWB model parameters in Sogamoso River basin

## Usage

``` r
gru_maps
```

## Format

list and raster

- alpha1:

  a vector with alpha1 values for each GRU

- alpha2:

  a vector with alpha2 values for each GRU

- smax:

  a vector with Smax values for each GRU

- d:

  a vector with d values for each GRU

- alpha1R:

  a raster with alpha1 values for each GRU

- alpha2R:

  a raster with alpha2 values for each GRU

- smaxR:

  a raster with Smax values for each GRU

- dR:

  a raster with d values for each GRU
