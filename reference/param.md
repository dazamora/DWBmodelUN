# param

Values to four parameters (\\\alpha-1\\, \\\alpha-2\\, *`d`*, *`S_max`*)
of DWB model in each GRU

## Usage

``` r
param
```

## Format

data.frame

- param:

  Data frame, it should represent a GRU in each row, and parameter
  values in each column. GRU rank should match the GRU number used in
  the GRU raster.
