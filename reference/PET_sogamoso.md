# PET_sogamoso

Distributed monthly potential evapotranspiration in Sogamoso River Basin
from January 2012 to December 2016

## Usage

``` r
PET_sogamoso
```

## Format

data.frame

- PET_sogamoso:

  Data frame, it contains evapotranspiration data, representing the
  cells in each row, and the evapotranspiration info. by month in each
  column. The cell rank should match the cell ID in the cells data
  frame.

## References
