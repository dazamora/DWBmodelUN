# P_sogamoso

Distributed monthly precipitation in Sogamoso River Basin from January
2012 to December 2016

## Usage

``` r
P_sogamoso
```

## Format

data.frame

- P_sogamoso:

  Data frame, it should represent the cells in each row, and the
  precipitation info. by month in each column. The cell rank should
  match the cell ID in the cells data frame.

## References

Duque-Gardeazabal, N. (2018). "Estimation of rainfall fields in data
scarce colombian watersheds, by blending remote sensed and rain gauge
data, using kernel functions". Master thesis. Universidad Nacional de
Colombia, Bogotá, Colombia.
